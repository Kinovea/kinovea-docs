Main toolbar 
------------------

The main toolbar provides quick access to screen organization.

=====================    ========================
|Open|                   Opens a video
|Save|                   Saves annotations to the current KVA file
|NavPane|                Toggles the navigation pane visibility
|Browser|                Closes screens and shows the browser view
|Playback|               One playback screen
|DualPlayback|           Two playback screens
|Capture|                One capture screen
|DualCapture|            Two capture screens
|Hybrid|                 One playback screen and one capture screen
=====================    ========================

.. _navigation_pane:

Navigation pane
---------------------

The navigation pane is on the left hand side of the main Kinovea window.
It provides access to the file system and connected cameras.

To show or hide the navigation pane use the menu :menuselection:`View --> Navigation pane`, or the shortcut :kbd:`F4`.

It has the following tabs:

===============         ========================
|FileSystem|            File system
|Shortcuts|             Shortcuts
|Cameras|               Cameras
===============         ========================

.. |FileSystem| image:: /images/ui/icons/filesystem.png
.. |Shortcuts| image:: /images/ui/icons/star.png
.. |Cameras| image:: /images/ui/icons/cameras.png


File system
****************

The file system tab shows a tree view of the folders on your computer.
The bottom part of the tab shows a list of supported files found in the selected folder.

Shortcuts
****************

The shortcuts tab shows a tree view of bookmarked folders.

To add a shortcut, right click the folder and choose :menuselection:`Add to shortcuts`.


Cameras
****************

The cameras tab shows a list of the cameras currently connected to the computer and a history of recently recorded videos.

The Manual connection button opens a dialog to manually add network cameras or camera simulators.

See :doc:`Capture </capture/introduction>` for more information about connecting cameras.
